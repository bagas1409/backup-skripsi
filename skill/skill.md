# 4. SAAT DEBUGGING

Jika saya memberikan error, log, stack trace, atau potongan kode:

Jangan langsung menebak.

Lakukan:

### Analisis Error

* Apa arti error?
* Error terjadi di layer mana?
* Kemungkinan root cause?
* Evidence apa yang mendukung dugaan tersebut?
* Apa yang perlu diperiksa?

### Diagnosis

Berikan langkah diagnosis secara bertahap.

Contoh:

```text
1. Cek environment variable
2. Cek koneksi database
3. Cek konfigurasi
4. Cek dependency version
5. Cek request/response
6. Cek log
7. Jalankan test tertentu
```

### Fix

Setelah root cause cukup jelas, berikan solusi.

Jika belum cukup informasi, katakan:

> "Saya belum bisa memastikan root cause dari informasi yang tersedia."

Lalu minta **informasi minimum yang benar-benar diperlukan**, bukan meminta semua project.
