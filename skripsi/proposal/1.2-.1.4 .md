1. Rumusan Masalah
Berdasarkan uraian konteks latar belakang di atas, rumusan masalah dalam penelitian ini dirinci ke dalam empat pertanyaan ilmiah sebagai berikut:
Bagaimana mengimplementasikan arsitektur deep learning YOLOv8 varian Small Classification (yolov8s-cls) melalui pendekatan transfer learning untuk mengklasifikasikan tiga kondisi buah kakao (Black Pod Rot, Pod Borer, dan Healthy)?
Bagaimana kinerja model yolov8s-cls pada data uji independen yang diukur menggunakan metrik evaluasi Accuracy, Precision, Recall, F1-Score, dan matriks konfusi (Confusion Matrix) multi-kelas ?
Bagaimana mengonversi dan mengoptimasi model yolov8s-cls ke dalam format edge inference TensorFlow Lite (.tflite) agar dapat diintegrasikan ke dalam arsitektur aplikasi mobile React Native berbasis C++ JavaScript Interface (JSI) ?
Bagaimana merancang dan membangun aplikasi mobile Android luring (offline-first) menggunakan metode Waterfall yang mampu menyajikan diagnosis penyakit buah kakao secara instan dan menyimpan riwayat pemindaian ke dalam basis data lokal SQLite ?
2. Batasan Masalah
Agar penelitian terfokus pada sasaran ilmiah dan teknis yang telah digariskan, ditetapkan enam batasan masalah yang tegas sebagai berikut:
	Objek Citra Organ Buah: Objek klasifikasi dibatasi secara eksklusif pada organ buah kakao (Theobroma cacao L.) yang terbagi ke dalam tiga kelas kategori: Buah Sehat (Healthy), Busuk Buah Hitam (Black Pod Rot akibat Phytophthora palmivora), dan Penggerek Buah Kakao (Pod Borer akibat Conopomorpha cramerella). Penelitian tidak mencakup identifikasi penyakit pada daun, batang, atau akar.
	Dataset Penelitian: Data citra yang digunakan bersumber dari repositori publik Kaggle oleh Zaldy Jr (cacao-diseases) dengan total volume 4.300 citra beresolusi asli 1080×1080 piksel yang diambil pada perkebunan kakao.
	Mekanisme Visi Komputer: Sistem menerapkan paradigma Single-Image Classification (klasifikasi citra tunggal) menggunakan input dimensi 224×224 piksel. Penelitian ini bukan merupakan tugas Object Detection, tidak menghasilkan koordinat kotak pembatas (bounding box), dan secara absolut tidak menggunakan metrik mean Average Precision (mAP).
	Metrik Evaluasi: Evaluasi performa model klasifikasi diukur secara eksklusif melalui metrik Accuracy, Precision, Recall, F1-Score, dan Confusion Matrix 3-kelas.
	Platform Sistem Operasi: Aplikasi mobile dikembangkan khusus untuk sistem operasi Android (berbasis runtime Android SDK modern) menggunakan framework React Native (Expo SDK 54).
	Mekanisme Inferensi Tepi (Edge Computing): Proses inferensi deep learning berjalan 100% secara lokal pada perangkat keras seluler (on-device inference) tanpa melakukan komputasi atau pertukaran data ke peladen web/cloud eksternal, sehingga tidak membutuhkan koneksi jaringan internet.
3. Tujuan Penelitian
Tujuan yang hendak dicapai dalam penelitian ini berkesesuaian satu-ke-satu (1-to-1 mapping) dengan rumusan masalah, yaitu:
	Melatih dan mengonfigurasi model deep learning yolov8s-cls berbasis transfer learning bobot ImageNet untuk mengklasifikasikan citra buah kakao ke dalam kelas Black Pod Rot, Pod Borer, dan Healthy. 
	Mengukur dan menganalisis performa klasifikasi model yolov8s-cls pada data uji menggunakan metrik Accuracy, Precision, Recall, F1-Score, serta visualisasi Confusion Matrix.
	Melakukan kuantisasi dan konversi model hasil pelatihan ke format TensorFlow Lite (.tflite) berkinerja tinggi serta mengintegrasikannya dengan runtime React Native melalui antarmuka native C++ JSI (react-native-fast-tflite).
	Mengembangkan aplikasi mobile Android luring (offline-first) yang dilengkapi pemindai kamera real-time, penyaji diagnosis penyakit buah kakao, dan modul pencatatan riwayat berbasis basis data lokal expo-sqlite dengan Waterfall.
