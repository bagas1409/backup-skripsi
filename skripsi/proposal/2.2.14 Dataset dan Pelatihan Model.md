Penyusunan himpunan data (*dataset*) dan konfigurasi pelatihan model merupakan tahapan fundamental dalam rekayasa sistem visi komputer terawasi (*supervised learning*) untuk mendiagnosis patologi buah kakao (Alvarado et al., 2025; Ferraris et al., 2023). Kualitas representasi dan keberagaman data visual menentukan keandalan generalisasi model *deep learning* dalam mengenali karakteristik penyakit di kondisi perkebunan riil (Khan et al., 2023; Maylianti et al., 2025). Himpunan data citra buah kakao dikelompokkan ke dalam tiga kategori kelas target, yaitu Sehat (*Healthy*), Busuk Buah Hitam (*Black Pod Rot*), dan Penggerek Buah Kakao (*Pod Borer*) (Ariawan et al., 2025; Maylianti et al., 2025; Novanto et al., 2025). Citra masukan yang bersumber dari data primer lapangan maupun repositori terbuka distandarisasi ke resolusi $224 \times 224$ piksel serta dinormalisasi ke rentang nilai $[0, 1]$ (Ariawan et al., 2025; Gado & Primandari, 2025). Untuk menguji performa model secara objektif, himpunan data dipartisi secara proporsional ke dalam subset data latih (*training set*) dan data validasi (*validation set*) dengan rasio pembagian 80:20 (Ariawan et al., 2025; Maylianti et al., 2025).

Dalam proses pelatihan model klasifikasi multi-kelas, tujuan optimasi jaringan saraf diformulasikan untuk meminimalkan nilai fungsi kerugian *Categorical Cross-Entropy Loss* ($\mathcal{L}_{CE}$), yang mengukur derajat deviasi antara probabilitas prediksi model dengan label kebenaran dasar (*ground-truth labels*) (Maylianti et al., 2025; Terven et al., 2023). Formulasi matematis fungsi kerugian dirumuskan sebagai berikut:

$$\mathcal{L}_{CE} = -\sum_{c=1}^M y_c \log(\hat{y}_c)$$

di mana $M$ merepresentasikan jumlah total kelas klasifikasi target ($M = 3$ untuk kelas Sehat, Busuk Buah Hitam, dan Penggerek Buah Kakao), $y_c$ merupakan nilai biner bernilai 1 jika sampel tergolong ke dalam kelas *ground-truth* $c$ dan bernilai 0 untuk kelas lainnya, serta $\hat{y}_c$ melambangkan probabilitas posterior prediksi model untuk kelas $c$ yang dihitung melalui fungsi aktivasi *Softmax* pada lapisan keluaran klasifikasi (Maylianti et al., 2025; Novanto et al., 2025; Terven et al., 2023).

Pembaruan bobot parameter jaringan selama siklus pelatihan dilakukan menggunakan algoritma pengoptimal adaptif berbasis gradien, seperti *Adam* (*Adaptive Moment Estimation*) dan *RMSProp*, yang secara empiris terbukti mampu mempercepat konvergensi dan menjaga stabilitas gradien pada data citra penyakit kakao (Gado & Primandari, 2025; Maylianti et al., 2025; Novanto et al., 2025). Kinerja pelatihan dikendalikan melalui penyelarasan hiperparameter (*hyperparameter tuning*) terukur, meliputi laju pembelajaran (*learning rate*) pada rentang 0,01 hingga 0,0001, ukuran tumpukan sampel per iterasi (*batch size*) sebesar 16 atau 32, serta batasan jumlah siklus iterasi penuh (*epochs*) antara 25 hingga 50 *epoch* guna menyeimbangkan efisiensi komputasi waktu pelatihan dan memitigasi timbulnya fenomena lewat-latih (*overfitting*) (Ghafar et al., 2024; Maylianti et al., 2025; Novanto et al., 2025; Siahaan et al., 2024).
