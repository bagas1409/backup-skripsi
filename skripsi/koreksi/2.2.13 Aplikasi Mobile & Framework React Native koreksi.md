# Tabel Audit dan Koreksi Sub-Bab 2.2.13 Aplikasi Mobile & Framework React Native

Dokumen ini memuat audit dan perbandingan antara draf naskah terdahulu dengan naskah baru di [2.2.13 Aplikasi Mobile & Framework React Native.md](file:///d:/backup/proyek-kerja/proyek%20ku/skripsi/skripsi/proposal/2.2.13%20Aplikasi%20Mobile%20&%20Framework%20React%20Native.md) yang **100% diverifikasi langsung dari berkas [jurnal referensi](file:///d:/backup/proyek-kerja/proyek%20ku/skripsi/skripsi/jurnal%20referensi)** aktif (2023–2025).

## 1. Masalah pada Draf Terdahulu

Pada draf naskah terdahulu, ditemukan sejumlah pelanggaran sitasi ilmiah (*citation fabrication/mismatch*) yang sangat krusial:
1. **Fabrikasi Sitasi pada Siahaan et al. (2024)**:
   - Draf lama mengklaim bahwa *"Aplikasi mobile native yang dikembangkan menggunakan framework React Native memungkinkan penulisan kode berbasis bahasa TypeScript yang dikompilasi secara efisien ke dalam komponen native Android dan iOS (Siahaan et al., 2024)"*. Faktanya, artikel ilmiah *Siahaan et al. (2024)* meneliti perancangan prototipe aplikasi bergerak Android menggunakan model YOLOv8 terkonversi TFLite untuk deteksi objek real-time, sama sekali tidak membahas bahasa TypeScript maupun kompilasi React Native ke iOS.
2. **Fabrikasi Sitasi pada Natbais & Umbu (2023)**:
   - Draf lama mengatribusikan konsep teknis *"mekanisme komunikasi baru berbasis JavaScript Interface (JSI) yang memegang referensi memori langsung (direct C++ host object reference) pada Expo SDK 54"* kepada `(Natbais & Umbu, 2023)`. Faktanya, artikel *Natbais & Umbu (2023)* meneliti aplikasi Android bertajuk *Tomato Leaf Disease* yang dikembangkan menggunakan bahasa pemrograman Java/Kotlin di Android Studio berbasis model terlatih TFLite, sama sekali tidak meneliti ekosistem Expo, JSI, atau referensi objek C++.
3. **Pencantuman Detail Pustaka Non-Akademis**:
   - Draf lama menyebutkan pustaka perangkat lunak spesifik `react-native-vision-camera v5.2.2` dan *Frame Processors* tanpa landasan pustaka jurnal. Konsep teknis ini disempurnakan menjadi arsitektur jembatan antarmuka *native* (*native bridge/interface*) dan *pipeline* inferensi citra terisolasi luring (*offline-first*) yang tervalidasi secara teoritis dalam literatur *edge AI mobile*.
